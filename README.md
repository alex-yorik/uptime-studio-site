# Uptime Studio — Landing Page

Одностраничный маркетинговый сайт студии **Uptime Studio** («IT Solutions & CRM Integrations»), которая разрабатывает Telegram-ботов для малого бизнеса: запись на услуги, приём заявок, CRM и онлайн-оплата. Сайт знакомит посетителей с портфолио живых демо-ботов, преимуществами сотрудничества и тарифами, а также направляет заявку в Telegram.

Статический сайт без бэкенда — вся логика (анимации, частицы, плавный скролл) выполняется в браузере.

## Функциональность

- **Портфолио** — 4 живых демо-бота (маникюр, репетитор, стоматология, фитнес) с переходом в Telegram по кнопке «Попробовать бота»
- **Тарифы** — три прайс-пакета («Визитка», «Запись», «Под ключ») с ценами, сроками и составом работ
- **Блок преимуществ** — скорость запуска (~2 часа), гарантия 14 дней, легальность (самозанятый, чеки «Мой налог»), поддержка 24/7
- **CTA-механика** — все кнопки ведут в Telegram (`@alex_yanakov`), первая консультация бесплатна
- **Тёмный premium-дизайн** — glassmorphism, кастомный курсор, preloader, градиентные иконки Lucide

## Стек технологий

- Чистый **HTML5 + CSS3 + JavaScript** (один файл `index.html`, без сборки)
- **Tailwind CSS** (CDN) — утилитарная вёрстка
- **GSAP + ScrollTrigger** — scroll-анимации блоков
- **Three.js** (r128) — частицы в hero-секции
- **Lenis** — плавный скролл
- **Lucide Icons** — иконки (SVG-градиент)
- Шрифты: **Clash Display**, **Inter**

## Архитектура

```
uptime-studio-site/
├── index.html   # весь сайт: разметка, стили, скрипты (единый файл)
└── CNAME        # кастомный домен uptimestudio.ru
```

- Сайт статический: стили и скрипты подключены с CDN, серверная часть отсутствует.
- Разметка организована секциями: Header → Hero → Портфолио → Преимущества → Тарифы → CTA → Footer.
- Данные (тарифы, цены, ссылки на ботов) захардкожены в разметке.
- Все внешние зависимости подтягиваются с CDN при загрузке страницы.

## Деплой

Сайт развёрнут на **GitHub Pages** (домен `uptimestudio.ru`). Обновление — коммит и пуш в ветку по умолчанию:

```bash
git add index.html CNAME
git commit -m "Update landing"
git push origin main
```

Для запуска локально достаточно открыть `index.html` в браузере или поднять любой статический сервер:

```bash
python3 -m http.server 8000
```

## Безопасность

- В репозитории нет секретов и личных данных — только статическая разметка.
- Все внешние ссылки открываются с `rel="noopener"`, контакты передаются только через официальный Telegram.

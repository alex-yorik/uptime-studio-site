## 1. Определение темы, целевых ключей и интента страницы

**Основная тема:** разработка и продажа Telegram-ботов для онлайн-записи клиентов малому бизнесу (beauty, стоматология, фитнес, образование) с мини-CRM и веб-админкой.

**Целевые ключевые фразы (по приоритету):**
| Ключ | Частотность | Интент |
|---|---|---|
| «телеграм бот для записи клиентов» | высокий | коммерческий (выбор услуги) |
| «заказать телеграм бота для бизнеса» | средний | коммерческий (заказ) |
| «разработка телеграм бота» | средний | коммерческий |
| «телеграм бот для стоматологии» | средний | коммерческий, нишевый |
| «телеграм бот для салона красоты» | средний | коммерческий, нишевый |
| «бот для записи» / «онлайн-запись через telegram» | высокий | коммерческий |

**Интент:** транзакционный (купить/заказать готового бота, узнать цену, сроки), частично информационный (как это работает). Пользователь хочет понять стоимость, срок запуска и состав решения, посмотреть демо, связаться в Telegram.

**Вывод по позиционированию в SERP:** по всем трём целевым запросам выдача Google (регион RU) состоит из смеси (а) статей/инструкций (timeweb.com, aimylogic.com, amsales.ru, sendpulse.com), (б) конструкторов/SaaS (bothelp.io, online-zapis.com, rubitime.ru, botmother.ru) и (в) студий-разработчиков (skybots.ru, mrcheck.ru, bottec.ru, profi.ru-фриланс). Значит, конкурировать можно не только как «студия», но и как «готовое решение с демо» — это сильная сторона текущего лендинга.

### 5.2 Что есть у нас сейчас
`index.html` содержит два отдельных блока:

### 5.3 Критические недостатки нашей разметки
1. **Нет @graph** — сущности не связаны (Organization ↔ WebPage ↔ Service ↔ FAQ).

4. **Нет AggregateRating** — нет реальных отзывов (нельзя добавлять фиктивные оценки — нарушение правил Google).
5. **Нет BreadcrumbList, WebPage, WebSite.**
6. **Битая ссылка logo.png** — валидатор Rich Results выдаст предупреждение.
7. Offers используют строковый price без `url`, `availability`; priceRange нестандартного формата «15000-50000 RUB» (валидный, но для RU лучше «₽»).
8. **Противоречие:** в FAQ-разметке ответ «Базовый бот готов за 3-5 дней», а в блоке преимуществ «~2 часа» — разнобой данных.

## 6. Список критических SEO-упущений (итог)

**Технические/контентные:**
1. **Нет гео-таргетинга** на странице (Москва/Московская область) ни в Title, ни в тексте, ни в схеме → выпадаем из локальной выдачи «…в Москве».
2. **Семантическая дыра:** 0 вхождений «телеграм» (кириллица) и «чат-бот»; вся страница использует только «Telegram-боты». Для RU-SERP нужны оба написания + LSI («онлайн-запись», «автоматизация записи», «бот для записи», «запись клиентов»).
3. **Объём текста 4 370 символов** — в 2–3 раза меньше конкурентов; не хватает смысловых блоков (как работает, этапы, для кого, выгоды по нишам).
4. **Нет блока отзывов/кейсов с цифрами** → нельзя внедрять AggregateRating.
5. **Нет телефона и адреса** → невозможно корректно заполнить LocalBusiness.
6. **Битые ресурсы:** `og-image.png`, `favicon-16x16.png`, `favicon-32x32.png`, `web-app-manifest-512x512.png`, `logo.png` отсутствуют в репозитории → битые соцпревью, favicon-ошибки в Search Console.
7. **Нет robots-мета** (впрочем robots.txt разрешает всё; для главной не критично).
8. **Дублирование контента-несоответствий** в схемах и тексте (сроки запуска 3-5 дней vs 2 часа).
9. Sitemap не включает `blog/`-статьи актуальные даты? — включены обе статьи; главная OK.

## 7. Пошаговый план внедрения

**Шаг 1. Микроразметка JSON-LD (критично):**
- Заменить два разрозненных блока на единый `@graph`-граф: Organization (или ProfessionalService) ↔ WebPage ↔ Service/OfferCatalog ↔ FAQPage, добавив geo-координаты Москвы, телефон, email, areaServed, часы работы.
- Убрать/исправить битую ссылку logo.png (указать реальный og-image или убрать поле).

**Шаг 2. On-Page-мета (CTR):**
- Title ≤ 60 симв.: главный ключ + УТП (без гео, т.к. коротко; либо добавить гео вторым смыслом).
- Meta description ≤ 155 симв. с цифрами (сроки, цена) и CTA.
- Ввести кириллические и LSI-варианты в H2/H3 и тексты.

**Шаг 3. Контент:**
- Добавить блок «Как мы работаем» (этапы), «Для кого» (ниши с выгодами), калькулятор/сроки, согласовать цифры сроков.
- Добавить гео-упоминания Москва/МО и контакты (телефон — при наличии у владельца).

**Шаг 4. Активы:**
- Сгенерировать недостающие `og-image.png` (1200×630), favicon-16/32, manifest-512, logo.png.

**Шаг 5. Валидация:**
- Проверить JSON-LD в Rich Results Test / schema.org validator (офлайн: `json.loads` + проверка обязательных полей).

**Шаг 6. Техдолг и отчёт:**
- Зафиксировать несделанное (телефон, реальные отзывы) в `TECH_DEBT.md`/отчёте.
